03 / FIELD NOTES

Good evidence needs
good context.

Use this tool as a starting point. Keep the original evidence and verify conclusions independently.

01

Prepare the source

Map columns containing a timestamp, prepared event label, and device ID. Computer and user columns are optional.

02

Know the limits

This version does not read raw .evtx files, Windows Event Viewer exports, registry hives, or live USB devices directly.

03

Investigate responsibly

Event labels depend on preparation. A record or repeated ID cannot by itself prove physical insertion, file transfer, or compromise.
